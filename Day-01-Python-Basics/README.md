## 💻 Practice Problems

### 1. Temperature Converter

Write a Python program that takes a temperature in Celsius as input and converts it to Fahrenheit.

**Formula:**

F = (C × 9/5) + 32

**Sample Input**
```text
25
```

**Sample Output**
```text
77.00
```

---

### 2. Simple Interest Calculator

Write a Python program that takes the principal amount, rate of interest, and time as input and calculates the simple interest.

**Formula:**

SI = (P × R × T) / 100

**Sample Input**
```text
10000
5
2
```

**Sample Output**
```text
1000.00
```

---

### 3. Seconds to Hours, Minutes and Seconds

Write a Python program that takes a total number of seconds and converts it into hours, minutes, and seconds.

**Sample Input**
```text
3665
```

**Sample Output**
```text
1:1:5
```

---

### 4. Student Profile Formatter

Write a Python program that takes a student's name, age, department, and CGPA as input and displays the information in a formatted student profile using f-strings.

**Sample Input**
```text
Arun Kumar
19
AI & Data Science
8.6
```

**Sample Output**
```text
Name: Arun Kumar
Age: 19
Department: AI & Data Science
CGPA: 8.60
```
