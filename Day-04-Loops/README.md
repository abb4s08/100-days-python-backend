# 🟢 Problem 01 — Factorial of a Number

Write a Python program that takes a non-negative integer `n` and calculates its factorial using a loop.

The factorial of a number is:

`n! = n × (n-1) × (n-2) × ... × 1`

### Sample Input

5

### Sample Output

120

---

# 🟢 Problem 02 — Sum of Digits

Write a Python program that takes an integer and calculates the sum of its digits using a loop.

### Sample Input

5382

### Sample Output

18

### Explanation

5 + 3 + 8 + 2 = 18

# 🟡 Problem 04 — Reverse an Integer

Write a Python program that takes a positive integer and reverses its digits using a loop.

**Condition:** Do not use string slicing such as `[::-1]`.

### Sample Input

12345

### Sample Output

54321

---

# 🔴 Problem 05 — Fibonacci Series

Write a Python program that takes an integer `n` and prints the first `n` numbers of the Fibonacci sequence using a loop.

The Fibonacci sequence starts with:

`0 1 1 2 3 5 8 13 ...`

Each number after the first two is the sum of the previous two numbers.

### Sample Input

8

### Sample Output

0 1 1 2 3 5 8 13

# 🚀 Mini Project — Number Analyzer

Create a Python program that accepts a positive integer and analyzes it using the concepts learned so far.

The program should display:

- Number of digits
- Sum of digits
- Reversed number
- Whether the number is Even or Odd
- Factorial of the number

### Sample Input

5

### Sample Output

Number: 5  
Digits: 1  
Digit Sum: 5  
Reversed: 5  
Type: Odd  
Factorial: 120
